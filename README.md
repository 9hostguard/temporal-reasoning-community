# Temporal Reasoning Community

Welcome to the Temporal Reasoning Community repository! This is a hub for community-driven contributions like plugins, datasets, and experiments to advance temporal reasoning with ChatGPT.

## Repository Structure
```
temporal-reasoning-community/
├── plugins/
│   └── sample_plugin.py
├── datasets/
│   └── sample_dataset.csv
├── experiments/
│   └── sample_experiment.ipynb
├── README.md
├── CONTRIBUTING.md
```

## How to Contribute
- Add plugins to the `plugins` directory.
- Upload datasets in the `datasets` folder.
- Write and share experiments in the `experiments` folder.
